AI Blog Generator API List:

1. Authentication APIs:

Method	     Endpoint					Description
POST	     /api/auth/register				Register a new user (token generation)
POST	     /api/auth/login				Login user and return JWT & Refresh Token
POST	     /api/auth/refresh-token			Generate a new JWT using Refresh Token
POST	     /api/auth/logout				Logout user and revoke refresh token

GET	     /api/profile/following	                Get users I follow

GET	     /api/profile/{userId}/following    	Get another user's following

GET          /api/profile/saved-blogs                   View saved blogs
GET	     /api/profile/liked-blogs	                View blogs liked by logged-in user
GET          /api/profile/{userId}/stats                Get User Statistics

GET          /api/profile/activity                      View user's activity history (published, liked, commented, reposted)
GET	     /api/profile/search	                Search users by username or display name

GET          /api/profile/{userId}/badges               Get all badges/achievements earned by a user
