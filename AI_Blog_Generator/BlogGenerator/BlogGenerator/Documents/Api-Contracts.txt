# AI Blog Generator – API Contract

## 1. Authentication APIs

### 1.1 Register User

**Endpoint:**
`POST /api/auth/register`

**Authorization:** Public

**Request**

```json
{
  "userName": "johnsmith",
  "email": "john@example.com",
  "password": "Password@123"
}
```

**Success Response — 201 Created**

```json
{
  "success": true,
  "message": "User registered successfully.",
  "data": {
    "accessToken": "",
    "refreshToken": "",
    "expiresIn": 3600,
    "user": {
      "userId": 1,
      "userName": "johnsmith",
      "email": "john@example.com",
      "role": "User",
      "availableCredits": 100,
      "profilePictureUrl": null
    }
  }
}
```

**Error Responses**

**400 Bad Request**

```json
{
  "success": false,
  "message": "Validation failed.",
  "errors": {
    "userName": ["Username is required."],
    "email": ["A valid email address is required."],
    "password": [
      "Password must contain at least 8 characters including uppercase, lowercase, number and special character."
    ]
  }
}
```

**409 Conflict**

```json
{
  "success": false,
  "message": "Username already exists."
}
```

**409 Conflict**

```json
{
  "success": false,
  "message": "Email is already registered."
}
```

### 1.2 Login

**Endpoint:**
`POST /api/auth/login`

**Authorization:** Public

**Request**

```json
{
  "email": "john@example.com",
  "password": "Password@123"
}
```

**Success Response — 200 OK**

```json
{
  "success": true,
  "message": "Login successful.",
  "data": {
    "accessToken": "",
    "refreshToken": "",
    "expiresIn": 3600,
    "user": {
      "userId": 1,
      "userName": "johnsmith",
      "email": "john@example.com",
      "role": "User",
      "availableCredits": 95,
      "profilePictureUrl": "https://cdn.aiblog.com/profile/1.jpg"
    }
  }
}
```

**401 Unauthorized**

```json
{
  "success": false,
  "message": "Invalid email or password."
}
```

**403 Forbidden**

```json
{
  "success": false,
  "message": "Your account has been suspended."
}
```

# 18. API Design Notes

* All authenticated endpoints use JWT Bearer authentication.
* Refresh tokens are stored and can be revoked during logout.
* Users receive **100 free credits** upon registration.
* AI operations deduct credits according to the configured credit pricing.
* A user's available credits cannot become negative.
* AI operations are blocked when the user has insufficient credits.
* Users can manage only their own blogs, comments, bookmarks, likes, reposts and profile information.
* Public users can view published blogs and public profiles.
* Only published blogs are available through the public feed.
* Only administrators can access administrative endpoints.
* Blog reports are reviewed and resolved by administrators.
* Stripe webhooks are used to receive payment events and update payment status.
* Deleted user accounts are retained in the `DeletedAccounts` archive without a foreign-key relationship to `Users`.
* Copying blog content is handled by the frontend/browser and therefore does not require a backend API.
* AI-generated operations create corresponding blog versions where applicable.
* Notifications are generated for relevant social interactions such as likes, comments, follows and reposts.
